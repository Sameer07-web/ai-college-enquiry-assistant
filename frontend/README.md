# Frontend — React

This directory will contain the React + TypeScript application, created with Vite.

## Planned areas
- Student chat and conversation history
- Source citations and excerpts
- Authorized college selection
- Admin document dashboard
- Upload and processing status
- Feedback and error states

## Initial setup
Create a Vite React TypeScript project in this directory. Add Tailwind CSS using its current official setup instructions. Keep API base URLs in environment configuration and never put server-side secrets in frontend variables.
